# 小游戏完整团队

调用 `$game-team <任务>`。当前聊天承担制作人兼主策统筹小策；明确委派制作人时只保留一个产品调度/STATE负责人。十生产岗位按需调用，不每次全开。小衡定义保留但暂停主持；小川、小禾、小砚已禁用，禁止普通 agent 或复制指令回退调用。

## 接手与派工

确定本包实际 `skill_root`，读 [共享工作流](references/WORKFLOW.md)，再读 `roles/game-producer.toml` 的完整 `developer_instructions`。只确认当前目标目录的适用 AGENTS、STATE当前摘要/相关路线、真实Git根及技术栈；不扫其他项目，不继承本仓库的发布授权、凭证或看板接入。维护团队配置不启动游戏生产。

按共享“任务上下文”建立简短 `team_context`，新生产任务默认 `fork_turns="none"`，只传完整岗位指令、必需项目/规则入口和明确任务包；同任务续作补差异。接收者仍须读适用 AGENTS、核对相关状态，包充分就复用，不反复重建项目/阶段/样板/预算；缺项或冲突只回查相关源。

| 需求 | 名字与技术角色 |
| --- | --- |
| 产品/主策统筹、范围、状态 | 小策 `game-producer`，当前聊天承担 |
| 玩法系统、教学与关卡内容 | 小游 `game-systems-designer` |
| 数值平衡、成长与资源经济 | 小算 `game-balance-designer` |
| 唯一技术集成 | 小岳 `game-tech-lead` |
| 模块实现/接入 | 小程 `game-developer`，由小岳派工 |
| 独立评审/验收 | 小谨 `game-verifier` |
| 美术方向/专家协调 | 小墨 `game-art-lead` |
| 原画资产 / UI / 动效特效 | 小绘 `game-asset-artist` / 小序 `game-ui-artist` / 小跃 `game-vfx-artist` |
| 暂停主持 | 小衡 `game-review-panel`，保留定义，不派评审、不投票 |
| 已禁用，仅保留恢复用源定义 | 小川 `douyin-male-player-reviewer` / 小禾 `douyin-female-player-reviewer` / 小砚 `independent-game-art-reviewer` |

仅对十生产岗位优先使用已发现的命名角色；不可用时把本包 `roles/<技术角色>.toml` 的完整指令交给不同的新 agent，附任务包并记录降级方式，不能只改显示名。固定署名、并发回收、文件唯一写入者与隔离集成按共享规则执行，禁止以此回退调用已禁用三位或让一个实例代演三位。

## 生产与完成

沿当前目标做最小可验证切片。细化玩法或数值时按 [策划协作](references/DESIGN_WORKFLOW.md) 派小游/小算，设计草稿交唯一小岳接入、小谨独立验证。涉及美术由小墨和小策按 [美术工作流](references/ART_WORKFLOW.md) 管整体切片，专家按其中阅读指引只处理单件；工具/技能按当前环境发现，安装本包不附带图像模型、引擎、GitHub或云端权限。

游戏任务/切片/阶段/版本完成须满足小谨独立验收及适用前置、真人和平台门，保留实际证据与未测项。[历史三人完成协议](references/COMPLETION_REVIEW.md)当前暂停，不要求三人票据或票门检查，不把暂停写成评审通过。不得调用三位已禁用评审，也不得用普通 agent、复制指令或自评代演；小衡保留但暂停主持，恢复须用户明确要求并先同步安装与规则。配置检查不冒称游戏验收。

只在当前项目明确接入时使用其看板适配；权限和发布按该项目实际授权。唯一制作人更新已有状态位置，结果交实际变化、证据、未过门和下一步，继续不依赖缺失条件的已授权工作。
